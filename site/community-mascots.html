{{Send yours. One file, one pull request.||Mande o seu. Um arquivo, um pull request.}}

  1. {{Build a look in Settings → Mascot → Customize and press Save as file, or write the file by hand with Writing mascots. The app watches the folder: saving the file updates the mascot right away.||Monte um visual em Configurações → Mascote → Personalizar e aperte Salvar como arquivo, ou escreva o arquivo à mão com Escrevendo mascotes. O app vigia a pasta: salvar o arquivo atualiza o mascote na hora.}}
  2. {{Check it in the app: no error on its card under Mascot files, and every expression looks right in the big preview (the buttons under it switch the face, the headset and the tape).||Confira no app: nenhum erro no cartão dele em Arquivos de mascote, e toda expressão bonita na prévia grande (os botões embaixo dela trocam a cara, o fone e a fita).}}
  3. {{Fill in the mascot node: a name, author=, license= and description=.||Preencha o nó mascot: um nome, author=, license= e description=.}}
  4. {{Fork the repository, add the file to mascots/community/ and open a pull request. One mascot per pull request; a screenshot in the pull request helps.||Faça um fork do repositório, coloque o arquivo em mascots/community/ e abra um pull request. Um mascote por pull request; uma captura de tela no pull request ajuda.}}
  • {{Data, not code. A mascot file only picks parts, colors and shapes. The app limits it to 64 KB, 256 shapes and 4096 points, and stops at the first problem with file:line:column.||Dado, não código. Um arquivo de mascote só escolhe peças, cores e formas. O app limita a 64 KB, 256 formas e 4096 pontos, e para no primeiro problema com arquivo:linha:coluna.}}
  • {{A name of its own and an original drawing: don't redraw someone else's character or logo.||Um nome só dele e um desenho original: nada de redesenhar personagem ou logo de outra pessoa.}}
  • {{An open license. license= written as its SPDX identifier (CC0-1.0, CC-BY-4.0, MIT…), so people know they may use and change it.||Uma licença aberta. license= escrita pelo identificador SPDX (CC0-1.0, CC-BY-4.0, MIT…), para todo mundo saber que pode usar e mudar.}}
  • {{Only .kdl files go in the folder. The picture on this page is made when the gallery is updated.||Só arquivos .kdl na pasta. A imagem desta página é feita quando a galeria é atualizada.}}
