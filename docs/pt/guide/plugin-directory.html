Diretório de plugins

Os 9 plugins que vêm dentro do app, com o que cada um pede. Configurações → Plugins → Instalar os incluídos copia os que você não tem para a sua pasta de plugins; nunca sobrescreve um arquivo que você editou. Os que usam a internet não mandam nada antes de você aprovar o host no cartão deles.

Esta página é gerada dos próprios arquivos (docs/plugins/) e dos rótulos que o app mostra no cartão de cada plugin, então bate com o que você vê nas Configurações. Para escrever o seu, comece pelo gerador de plugin e pela API.

#Anti-golpe

scamguard.lua · versão 1.0.0 · código

Marca em vermelho os golpes clássicos de Discord nas mensagens dos outros: endereços que imitam o Discord ou a Steam, Nitro grátis e presentes falsos com link, links encurtados com isca, links que mostram um endereço e abrem outro. Só olha as mensagens com link, neste computador, sem rede nenhuma. Diga "Não é golpe" numa mensagem e aquele endereço nunca mais é marcado.

PedeO que isso permite
Lê mensagens (messages)Vê as mensagens que chegam e as carregadas, de qualquer canal
Marca mensagens (decorate)Selos, notas e recolher, só na sua tela
Menus (menu)Entradas no botão direito de mensagens e pessoas
Painel (panel)Um painel lateral próprio
Guarda dados (storage)Até 1 MB neste computador, separado por conta
Opções (settings)As opções dele aparecem neste cartão
Avisos (notify)Avisos na janela e notificações do sistema
Temporizadores (timers)Roda depois de um tempo, só enquanto estiver ligado
  • Comandos: /scam
  • Botão direito numa mensagem: Não é golpe
  • Painel: pelo botão no topo do canal ou pela paleta (Painel: nome)

#Cartões do GitHub

github.lua · versão 1.0.0 · código

dono/repo#123 e links para issues, pull requests e repositórios do GitHub ganham uma nota com o título, o estado e as estrelas. Só o nome do repositório e o número vão para api.github.com, e só depois de aprovar o host aqui embaixo. Só repositórios públicos, sem login: o GitHub deixa poucos pedidos por hora sem ele, então cada resposta fica guardada por um tempo, e passado o limite as notas só esperam.

Internet (http)Só HTTPS, só para os hosts abaixo, e depois que você aprovar
Guarda dados (storage)Até 1 MB neste computador, separado por conta
Temporizadores (timers)Roda depois de um tempo, só enquanto estiver ligado
  • Fala com: api.github.com, só depois de você aprovar no cartão

O cartão mostra: “Lê suas mensagens e fala com a internet. Só ligue se confiar em quem fez.”

#Links limpos

cleanlinks.lua · versão 1.0.0 · código

Tira o rastreio dos links que você envia (utm_*, fbclid, o si do YouTube e do Spotify e afins), e a outra pessoa recebe só o endereço. São regras fixas que o app aplica ao enviar: o plugin não vê o que você escreve e não gasta nada enquanto você digita.

#Radar de CVE

cve.lua · versão 1.0.0 · código

Acha CVE-2021-44228 e afins nas mensagens e mostra embaixo a severidade, a nota CVSS e um resumo curto, do registro oficial de CVEs. Só o número do CVE vai para cveawg.mitre.org, e só depois de aprovar o host aqui embaixo. Cada um é pedido uma vez e fica guardado por dias. /cve CVE-2021-44228 consulta um na mão.

#Traduzir

translate.lua · versão 1.1.0 · código

Botão direito numa mensagem, ou o 🌐 na barra dela, para ver a tradução embaixo. "Traduzir para…" escolhe outro idioma só para aquela mensagem, as opções abaixo definem o padrão, e /tr es olá põe uma tradução na caixa de mensagem. O texto vai para api.mymemory.translated.net (um serviço público e gratuito) só quando você pede, e só depois de aprovar o host aqui embaixo.
