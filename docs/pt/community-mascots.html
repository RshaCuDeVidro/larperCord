Mascotes da comunidade. Desenhados num arquivo, usados no app.

O mascote Terminal veste qualquer coisa: em Configurações → Mascote → Personalizar você escolhe olhos, bocas, chapéus, acessórios, orelhas e cores, e um arquivo de mascote pode desenhar as próprias peças com formas, um desenho por expressão. Estes são arquivos que as pessoas fizeram e mandaram para o repositório. Baixe um, coloque na sua pasta de mascotes e aperte Usar no cartão dele no app. Como escrever um está em Escrevendo mascotes.

pull request { // como mandar o seu

Mande o seu. Um arquivo, um pull request.

  1. Monte um visual em Configurações → Mascote → Personalizar e aperte Salvar como arquivo, ou escreva o arquivo à mão com Escrevendo mascotes. O app vigia a pasta: salvar o arquivo atualiza o mascote na hora.
  2. Confira no app: nenhum erro no cartão dele em Arquivos de mascote, e toda expressão bonita na prévia grande (os botões embaixo dela trocam a cara, o fone e a fita).
  3. Preencha o nó mascot: um nome, author=, license= e description=.
  4. Faça um fork do repositório, coloque o arquivo em mascots/community/ e abra um pull request. Um mascote por pull request; uma captura de tela no pull request ajuda.
  • Dado, não código. Um arquivo de mascote só escolhe peças, cores e formas. O app limita a 64 KB, 256 formas e 4096 pontos, e para no primeiro problema com arquivo:linha:coluna.
  • Um nome só dele e um desenho original: nada de redesenhar personagem ou logo de outra pessoa.
  • Uma licença aberta. license= escrita pelo identificador SPDX (CC0-1.0, CC-BY-4.0, MIT…), para todo mundo saber que pode usar e mudar.
  • Só arquivos .kdl na pasta. A imagem desta página é feita quando a galeria é atualizada.
