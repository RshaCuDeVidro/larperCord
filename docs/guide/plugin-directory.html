Plugin directory

The 9 plugins that come inside the app, with what each one asks for. Settings → Plugins → Install bundled plugins copies the ones you don't have into your plugins folder; it never overwrites a file you've edited. The ones that use the internet send nothing until you approve the host on their card.

This page is generated from the files themselves (docs/plugins/) and from the labels the app shows on each plugin's card, so it matches what you'll see in Settings. To write your own, start with the plugin starter and the API.

#Clean links

cleanlinks.lua · version 1.0.0 · source

Removes tracking from the links you send (utm_*, fbclid, YouTube's si, Spotify's si and the like), so the other person gets just the address. Fixed rules the app applies when you send: the plugin doesn't see what you write and uses nothing while you type.

It asks forWhat that allows
Changes what you send (rewrite)Fixed rules applied to the text as you send; the plugin doesn't see what you write

#CVE radar

cve.lua · version 1.0.0 · source

Finds CVE-2021-44228 and the like in messages and shows the severity, the CVSS score and a short summary under them, from the official CVE record. Only the CVE number goes to cveawg.mitre.org, and only after you approve the host below. Each one is asked once and kept for days. /cve CVE-2021-44228 looks one up by hand.

#GitHub cards

github.lua · version 1.0.0 · source

owner/repo#123 and links to GitHub issues, pull requests and repositories get a note with the title, the state and the stars. Only the name of the repository and the number go to api.github.com, and only after you approve the host below. Public repositories only, no login: GitHub allows few requests per hour without one, so each answer is kept for a while, and past the limit the notes just wait.

#Scam guard

scamguard.lua · version 1.0.0 · source

Marks in red the classic Discord scams in other people's messages: addresses that imitate Discord or Steam, fake free Nitro and gifts with a link, shortened links with bait, links that show one address and open another. It only looks at messages with a link, in this computer, with no network. Say "Not a scam" on a message and that address is never marked again.

#Translate

translate.lua · version 1.1.0 · source

Right-click a message, or use the 🌐 on its toolbar, to see a translation under it. "Translate to…" picks another language for one message, the options below set the default, and /tr es hello puts a translation in the message box. The text goes to api.mymemory.translated.net (a free public service) only when you ask, and only after you approve the host below.
