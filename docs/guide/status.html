Status and roadmap

larperCord is a young project: version 0.6.5, with its first commit on November 2, 2026. It's usable, but it isn't complete.

#What works today

AreaStateDetail
Messages, DMs, reactions, repliesworksSend, edit, delete, history, mentions, send options, poll voting, who reacted
Bots and appsworksButtons, select menus, forms (modals) and slash commands. App commands in the right-click menu and files in bot forms are missing
ImagesworksAvatars and attachments, with a fixed-size cache
Video in chatworksAttachments and direct links. Needs FFmpeg 7, 8 or 9: your distro's on Linux, or the Download FFmpeg button in Settings → Chat on Windows
Inbox, saved messages, offline searchworksAll local, can be turned off and erased
Multiple accounts, proxy, Lua pluginsworks
Account settingsworksBlock, ignore, friend requests, mute and notification levels, status with a duration, custom status, display name, pronouns and About me, synced with your Discord account. The picture and banner, and your own server profiles, are still changed in the official app
Server profilesworksEach person's server nickname, picture, bio, pronouns and banner, wherever they appear in that server
ModerationworksKick, ban, timeout, server mute and deafen, the bans list. Only the actions your role allows appear
Rich PresenceworksOff by default
Threads and forumsworksNested threads, forum post lists, creating and editing threads and posts, archived and private ones
Custom emoji, stickers, autocompleteworksAnimated too. The picker warns when an emoji needs Nitro, and the GIF picker sends stickers
Arabic, Hebrew and other scriptspartialThey display in messages and in the message box, and a system font fills in letters any theme lacks. Scripts that need shaping (Devanagari, Bengali, Thai, Khmer…) show their letters one by one, without conjuncts or reordered vowel signs
LanguagesworksEnglish, Portuguese, Japanese and Russian, one translation file each
Read state, pins, Discord linksworksSynced with your other devices
Themesworks11 built-in, each light and dark, reload on save
VoicepartialServer voice channels and DM and group calls, with the call screen. E2EE (DAVE), the mixer with Remove noise and Even out volume per person, mute, device picker, push-to-talk, high-pass filter, noise gate and RNNoise noise suppression work. On Linux, push-to-talk needs the window focused, and no automated test covers a real call
PermissionspartialChannels without access get a padlock, voice without permission is blocked, and the message box says why you can't send (no permission, a locked thread, a timeout, slowmode). Those channels still appear, and reactions and the member list don't check permissions
System tray, updatesworksThe icon stays in the tray while the app runs and closing keeps it there; signed updates from Settings. On Linux the tray needs a StatusNotifier panel
WindowspartialWindows 10/11 from the same code. Newer than Linux and less used
NotificationspartialThrough notify-send on Linux and the tray on Windows. Clicking doesn't open the channel
Keyboard shortcutsworksThe main ones can be changed in Settings → Keybinds, and vim navigation is optional
AccessibilitypartialFont scale, interface size, reduced motion, palette and vim navigation. No visible focus and no high contrast
First runpartialSign-in screen and demo mode, no introduction to the app
PlatformspartialLinux and Windows. The Linux build needs glibc 2.34 or newer. It's used daily on Arch with Hyprland, and opened in Ubuntu, Debian, Fedora, openSUSE and Arch containers, in demo mode, before each release. The Windows build has only been run in CI and in a sandbox, in demo mode
Joining a server by inviteworksFrom an invite card, a link or a code, with a warning first. Servers with rules or onboarding open them in the app
Screen sharing and cameramissing

#Roadmap

Done

  • Real gateway (WebSocket, heartbeat, reconnects) and REST respecting rate limits
  • Session RESUME and zlib-stream
  • Presences, members and server and channel events
  • Images: avatars, attachments and custom emoji with a fixed-size cache
  • Voice: voice gateway, UDP, Opus and DAVE/MLS
  • Voice settings: device picker, push-to-talk, filters and call sounds
  • Threads and forums
  • Stickers, the full emoji picker and autocomplete
  • Read state synced with Discord, pinned messages, Discord links in the app
  • Theme engine: gradients, patterns, grain, vignette, display typography, shapes and rules, procedural backgrounds
  • Joining a server by invite
  • Calls in DMs and groups
  • Rich Presence: show the game you're playing, off by default
  • Moderation: kick, ban, timeout, and server mute and deafen
  • Bot buttons, menus, forms and slash commands
  • Account settings synced with Discord: block, ignore, friends, mute, status and profile
  • Arabic and Hebrew, and fonts for any script
  • On the site: a theme builder, a community theme gallery and a demo in the browser
  • Russian interface
  • Push-to-talk from any window, on Windows
  • Call screen, one tile per person, in the theme's style
  • Server profiles: nickname, picture, bio and banner per server
  • Remove noise and Even out volume per person in the mixer
  • Keybinds you can change
  • Typing Arabic and Hebrew in the message box
  • The Terminal mascot, its openings and the corner mascot

Next

  • Open from the saved servers, channels and messages, then sync when Discord answers
  • A texture atlas for avatars and emoji
  • Server and role settings
  • A better theme editor
  • More versatile and more powerful plugins
  • Windows as a single .exe (an experimental build option already makes one)

To make the app complete

  • Real permissions: hide what you can't see, disable reactions, filter members
  • Shaping for complex scripts (Devanagari, Bengali, Thai, Khmer…)
  • Native D-Bus notifications with "open conversation"
  • Voice: a global push-to-talk on Linux and an automated call test
  • Accessibility and first run: visible focus, high contrast, a welcome screen

Themes

  • Engine: overlay and z-order, fonts and images bundled with a theme
  • Gallery and editor: real thumbnails, import and export .kdl, a component inspector
  • Theme components written in Lua (sandboxed)

Later

  • A software backend (wl_shm, no GPU), to get to about 15–20 MB
