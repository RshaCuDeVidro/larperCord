Contrast

    How contrast is checked

    The first two lines are the app's own rule: when muted or faint falls below it against bg, surface, sidebar or elevated, the app lifts it toward text on load (translucent colors are measured without their transparency, as the app does). The other lines are the WCAG AA minimum for text, measured as the colors show on the background. When a block in the layout replaces a color, the check uses the color the app will show.

      Type and shape

      Linux: any family fontconfig knows (fc-list lists them). Windows: only C:\Windows\Fonts. A file named like the family in lowercase, with no spaces (Cascadia Code → cascadiacode.ttf), is used for every weight, so there's no real bold or italic. Otherwise names with mono, code, consol, courier or term get Consolas, names with serif, georgia, times, garamond or playfair (and no sans) get Georgia, DejaVu Sans and DejaVu Sans Mono get Segoe UI Symbol, and the rest get Segoe UI. Fonts installed only for your user aren't seen. The preview uses the font if your browser has it.

        my-theme.kdl
        1. Put my-theme.kdl in ~/.config/larpercord/themes/ (or $XDG_CONFIG_HOME/larpercord/themes/ when that variable is set):
          bash
          mkdir -p ~/.config/larpercord/themes
mv ~/Downloads/my-theme.kdl ~/.config/larpercord/themes/
        2. If the folder didn't exist before, restart larperCord once: Settings → Updates → Restart larperCord, or Quit from the tray icon's menu and open it again (with a tray, closing the window only sends the app there). The app watches the theme folders that exist when it opens. From then on, saving the file reloads the window.
        3. Pick it with F2, in the palette (CtrlK → "theme: my-theme") or in Settings → Appearance. Or open the app with it:
          bash
          larpercord --theme my-theme

          This only works when larperCord isn't running yet. If it's in the tray, a second start just brings the window back, so quit it first.

        1. Put my-theme.kdl in %APPDATA%\larpercord\themes\. In PowerShell:

          New-Item -ItemType Directory -Force "$env:APPDATA\larpercord\themes" | Out-Null
Move-Item "$HOME\Downloads\my-theme.kdl" "$env:APPDATA\larpercord\themes\"
        2. If the folder didn't exist before, restart larperCord once: Settings → Updates → Restart larperCord. Closing the window isn't enough, because by default it only hides the app in the tray (to quit from there, right-click the tray icon, choose Quit and open it again). The app watches the theme folders that exist when it opens. From then on, saving the file reloads the window. Tip: paste %APPDATA%\larpercord\themes in File Explorer's address bar to open the folder.
        3. Pick it with F2, in the palette (CtrlK → "theme: my-theme") or in Settings → Appearance. Or open the app with it from PowerShell (that's where the install script puts it; from the zip, run .\larpercord.exe --theme my-theme in its folder):
          powershell
          & "$env:LOCALAPPDATA\Programs\larperCord\larpercord.exe" --theme my-theme

          This only works when larperCord isn't running yet. If it's in the tray, a second start just brings the window back, so quit it first.

        • The app lists a theme by its file name. A file with the name of a built-in theme (say orbital.kdl) takes its place.
        • If the file has an error, a notice shows file:line:column and the previous theme stays on screen.

        Import a theme

        Paste a .kdl or pick a file. Colors become fixed values (a theme that uses palette "wal" starts from the default palette); options, styles and layout come along as they are.

        Import colors from a Discord theme

        Paste a BetterDiscord or Vencord theme (.css or .theme.css, up to 500 KB) or pick the file. The page reads only the CSS variables that hold colors and maps the Discord ones (--background-primary, --text-normal, --brand-experiment, the newer --bg-base-*, --background-mod-* and --text-*…) to this theme's colors: dark mode, and light mode too when the CSS has a light block. Translucent surfaces are laid over the background so the app draws them solid. Nothing in the CSS runs or goes into the page, and @import links are listed, never opened. Layout, fonts and options stay as they are, and Undo brings the old colors back.

        Only use colors from a theme whose license lets you, and credit its author in the description if you share the result.
