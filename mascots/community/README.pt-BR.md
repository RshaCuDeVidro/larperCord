# Mascotes da comunidade

[English](README.md) · **Português**

Mascotes mandados por quem usa o larperCord. Cada `.kdl` daqui aparece na
[galeria de mascotes da comunidade](https://rshacudevidro.github.io/larperCord/pt/community-mascots.html) com
uma imagem e o arquivo para baixar. Os primeiros são exemplos, e cada um mostra uma parte do formato.

Para mandar o seu, ponha `seu-mascote.kdl` nesta pasta e abra um pull request. O nó `mascot` precisa de um nome,
`author=`, `license=` e `description=`. O formato e as regras estão em
[Escrevendo mascotes](../README.pt-BR.md#compartilhar-seu-mascote). Só arquivos `.kdl` aqui.

Para experimentar um, copie para a sua pasta de mascotes (Configurações → Mascote → Arquivos de mascote →
**Abrir pasta**) e aperte **Usar** no cartão dele.
