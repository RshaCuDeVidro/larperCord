# Community mascots

**English** · [Português](README.pt-BR.md)

Mascots sent in by people who use larperCord. Every `.kdl` here shows up in the
[community mascot gallery](https://rshacudevidro.github.io/larperCord/community-mascots.html) with a picture
and the file to download. The first ones are examples that each show off a part of the format.

To add yours, put `your-mascot.kdl` in this folder and open a pull request. The `mascot` node needs a name,
`author=`, `license=` and a `description=`. The format and the rules are in
[Writing mascots](../README.md#sharing-your-mascot). Only `.kdl` files go here.

To try one, copy it to your mascots folder (Settings → Mascot → Mascot files → **Open folder**) and press
**Use** on its card.
